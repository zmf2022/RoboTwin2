# 4×A100 全参微调与评测

环境、权重、数据同 `蚂蚁灵波具身智能挑战赛指南.md` §2～§3；模型路径不同时先改 `scripts/robotwin_local.yaml` 里的 6 处 `/mnt/datadisk/models/lingbot-vla`。

## 训练

```bash
cd lingbot-vla-v2
conda activate robotwin
export CUDA_VISIBLE_DEVICES=0,1,2,3
export NPROC_PER_NODE=4
NGPU=4
MBS=4   # OOM 改 2 或 1
PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True \
bash ../scripts/train.sh ../scripts/robotwin_local.yaml \
  --data.train_path $PWD/../data/training_data/RoboTwin_lerobot_v30 \
  --train.output_dir output_full/ \
  --train.max_steps 50000 \
  --train.save_steps 20000 \
  --train.micro_batch_size $MBS \
  --train.gradient_accumulation_steps $((1024 / (MBS * NGPU))) \
  --train.global_batch_size 1024 \
  --train.enable_gradient_checkpointing true \
  --data.image_augment true \
  --data.num_workers 4 \
  --data.prefetch_factor 1 > train.log 2>&1 &
```

### 断点续训

不删 `output_full`，用相同参数重跑，自动从最新的 `global_step_N` 恢复：

```bash
cd /data/zhangmingfa/RoboTwin2
MBS=8 setsid nohup bash run_train_4gpu.sh > lingbot-vla-v2/train_$(date +%m%d_%H%M).log 2>&1 < /dev/null &
# 或：等评测结束后自动续训（取消：pkill -f "while pgrep"）
setsid nohup bash -c 'while pgrep -f "scripts/[e]val.sh" >/dev/null; do sleep 60; done; MBS=8 bash run_train_4gpu.sh' > lingbot-vla-v2/train_$(date +%m%d_%H%M).log 2>&1 < /dev/null &
```

## 第二阶段：clean 随机化增强

从第一阶段的 `global_step_<N>/hf_ckpt` 初始化，开 random_aug 再训 10000 步，优化器和学习率从头开始。原理与调参见 `clean随机化增强指南.md`。

准备（一次性）：先停第一阶段，再同步代码、素材和修复后的数据。数据会覆盖 A100 上未修复的视频，不能边训边拷。

```bash
# A100
cd /data/zhangmingfa/RoboTwin2
pkill -f run_train_4gpu.sh; pkill -f train_lingbotvla.py
git stash && git pull && git stash pop   # robotwin_local.yaml 里改过模型路径，先 stash
# 本机（仓库根目录）
rsync -a data/random_aug/ <A100>:/data/zhangmingfa/RoboTwin2/data/random_aug/
rsync -a data/training_data/RoboTwin_lerobot_v30/ <A100>:/data/zhangmingfa/RoboTwin2/data/training_data/RoboTwin_lerobot_v30/
```

训练（4×A100 约 10 s/步，10000 步约 28 小时；每 5000 步存一次，只留最新 2 个）：

```bash
cd /data/zhangmingfa/RoboTwin2/lingbot-vla-v2
source /root/miniconda3/etc/profile.d/conda.sh && conda activate robotwin
export LD_PRELOAD=/root/miniconda3/envs/robotwin/lib/libstdc++.so.6
export CUDA_VISIBLE_DEVICES=0,1,2,3 PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True
NGPU=4
MBS=8      # OOM 改 4
N=15000    # 第一阶段起点
setsid nohup bash ../scripts/train.sh ../scripts/robotwin_local.yaml \
  --model.model_path $PWD/output_full/checkpoints/global_step_$N/hf_ckpt \
  --data.train_path $PWD/../data/training_data/RoboTwin_lerobot_v30 \
  --data.random_aug_config ../scripts/random_aug/random_aug.yaml \
  --data.image_augment true \
  --train.output_dir output_stage2/ \
  --train.lr 5.0e-5 --train.lr_min 1.0e-5 --train.lr_warmup_ratio 0.02 \
  --train.max_steps 10000 --train.save_steps 5000 --train.save_total_limit 2 \
  --train.micro_batch_size $MBS \
  --train.gradient_accumulation_steps $((256 / (MBS * NGPU))) \
  --train.global_batch_size 256 \
  --train.enable_gradient_checkpointing false \
  --data.num_workers 8 --data.prefetch_factor 2 > train_stage2_$(date +%m%d_%H%M).log 2>&1 < /dev/null &

tail -f log.txt
pkill -f train_lingbotvla.py   # 停止；不删 output_stage2、用相同命令重跑即断点续训
```

- 先冒烟：同一命令把 `--train.max_steps` 改成 20、`--train.output_dir` 改成 `output_stage2_smoke/`。日志里出现 `random_aug: prob=0.5 arm_masks=True`，并能跑完 20 步，就删掉 `output_stage2_smoke` 正式开跑。
- 评测：第 5000 步跑快速子集，第 10000 步跑全量；把下面评测命令里的 `output_full` 换成 `output_stage2`。
