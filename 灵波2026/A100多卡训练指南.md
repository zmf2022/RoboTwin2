# 4×A100 全参微调与评测

环境、权重、数据同 `蚂蚁灵波具身智能挑战赛指南.md` §2～§3；模型路径不同时先改 `scripts/robotwin_local.yaml` 里的 6 处 `/mnt/datadisk/models/lingbot-vla`。

## 训练

```bash
cd lingbot-vla-v2
conda activate robotwin
export CUDA_VISIBLE_DEVICES=0,1,2,3
export NPROC_PER_NODE=4
NGPU=4
MBS=4   # OOM 改 2 或 1
PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True \
bash ../scripts/train.sh ../scripts/robotwin_local.yaml \
  --data.train_path $PWD/../data/training_data/RoboTwin_lerobot_v30 \
  --train.output_dir output_full/ \
  --train.max_steps 50000 \
  --train.save_steps 20000 \
  --train.micro_batch_size $MBS \
  --train.gradient_accumulation_steps $((1024 / (MBS * NGPU))) \
  --train.global_batch_size 1024 \
  --train.enable_gradient_checkpointing true \
  --data.image_augment true \
  --data.num_workers 4 \
  --data.prefetch_factor 1 > train.log 2>&1 &
```

### 断点续训

不删 `output_full`，用相同参数重跑，自动从最新的 `global_step_N` 恢复：

```bash
cd /data/zhangmingfa/RoboTwin2
MBS=8 setsid nohup bash run_train_4gpu.sh > lingbot-vla-v2/train_$(date +%m%d_%H%M).log 2>&1 < /dev/null &
# 或：等评测结束后自动续训（取消：pkill -f "while pgrep"）

```

## 第二阶段：clean 随机化增强

从第一阶段 soup 20k+30k（`output_full/checkpoints/soup_20-30k/hf_ckpt`）起训，`random_aug_stage2.yaml`，5000 步，优化器和学习率从头开始（5e-5 → 1e-5）。

第一版第二阶段（`random_aug_s2.yaml`，已删）clean 升、randomized 降，根因是 teacher_clean：深度/视频教师看干净画面，学生必须从表征里抹掉贴图干扰物，只能学"是否贴图"；真实杂物不是贴图，被当成目标去抓。现在的第二阶段去掉 teacher_clean，并把干扰物贴到桌面后部和腕部。输出目录是 `output_stage2_v2/`：`output_stage2/` 里是第一版的 checkpoint，用同一目录会从它断点续训。详见 `clean随机化增强指南.md` §3。

准备：本机提交推送后在 A100 拉代码（`random_aug.py`、`utils.py`、`train_lingbotvla.py`、`random_aug_stage2.yaml`、`run_train_stage2_4gpu.sh`）；`data/random_aug/`、`data/dtd/dtd/images` 第一版已同步过。

```bash
cd /data/zhangmingfa/RoboTwin2
git stash && git pull && git stash pop   # robotwin_local.yaml 里改过模型路径，先 stash
# 冒烟（几分钟）
STEPS=20 SAVE=20 OUT=output_stage2_v2_smoke/ bash run_train_stage2_4gpu.sh 2>&1 | tee lingbot-vla-v2/train_stage2_v2_smoke.log
# 正式（约 9.3 s/步，5000 步约 13 小时；每 1000 步存一次）
setsid nohup bash run_train_stage2_4gpu.sh > lingbot-vla-v2/train_stage2_v2_$(date +%m%d_%H%M).log 2>&1 < /dev/null &
pkill -f train_lingbotvla.py   # 停止；用相同命令重跑即断点续训
```

- 冒烟通过的标准：日志有 `random_aug: prob=0.5 arm_masks=True textures=5640 files + procedural, distractors=3060` 和 `EMA decay=0.99 every=10`，前几步 `VLA_Loss` 约 0.01–0.03（约 0.36 说明没加载上 checkpoint），20 步跑完，`global_step_20/` 下有 `hf_ckpt` 和 `ema_hf_ckpt`。跑的时候 `free -g` 看一眼主机内存（EMA 每卡在 CPU 上约多占 6–13G）。然后删掉 `output_stage2_v2_smoke` 正式开跑。
- EMA 0.99（openpi 的做法）：只额外存一份滑动平均权重 `ema/`、`ema_hf_ckpt/`，原始训练不变；`EMA=0` 关闭。
- 磁盘：每 1000 步存一个 checkpoint（含 EMA 约 126G），默认保留 3 个约需 380G；开跑前 `df -h /data`。
- soup 不在 A100 上时用 `INIT=<hf_ckpt 路径>` 指定。
- 评测：第 3000 / 5000 步各跑全量，评测命令里的路径换成 `lingbot-vla-v2/output_stage2_v2/checkpoints/global_step_<N>/hf_ckpt`；第 5000 步再评一次同目录的 `ema_hf_ckpt`（结果目录名带 `_ema`）。
