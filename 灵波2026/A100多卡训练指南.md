# 4×A100 全参微调与评测

环境、权重、数据同 `蚂蚁灵波具身智能挑战赛指南.md` §2～§3；模型路径不同时先改 `scripts/robotwin_local.yaml` 里的 6 处 `/mnt/datadisk/models/lingbot-vla`。

## 训练

```bash
cd lingbot-vla-v2
conda activate robotwin
export CUDA_VISIBLE_DEVICES=0,1,2,3
export NPROC_PER_NODE=4
NGPU=4
MBS=4   # OOM 改 2 或 1
PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True \
bash ../scripts/train.sh ../scripts/robotwin_local.yaml \
  --data.train_path $PWD/../data/training_data/RoboTwin_lerobot_v30 \
  --train.output_dir output_full/ \
  --train.max_steps 50000 \
  --train.save_steps 20000 \
  --train.micro_batch_size $MBS \
  --train.gradient_accumulation_steps $((1024 / (MBS * NGPU))) \
  --train.global_batch_size 1024 \
  --train.enable_gradient_checkpointing true \
  --data.image_augment true \
  --data.num_workers 4 \
  --data.prefetch_factor 1 > train.log 2>&1 &
```

### 断点续训

不删 `output_full`，用相同参数重跑，自动从最新的 `global_step_N` 恢复：

```bash
cd /data/zhangmingfa/RoboTwin2
MBS=8 setsid nohup bash run_train_4gpu.sh > lingbot-vla-v2/train_$(date +%m%d_%H%M).log 2>&1 < /dev/null &
# 或：等评测结束后自动续训（取消：pkill -f "while pgrep"）
setsid nohup bash -c 'while pgrep -f "scripts/[e]val.sh" >/dev/null; do sleep 60; done; MBS=8 bash run_train_4gpu.sh' > lingbot-vla-v2/train_$(date +%m%d_%H%M).log 2>&1 < /dev/null &
```

## 第二阶段：clean 随机化增强

从第一阶段 soup 20k+30k（`output_full/checkpoints/soup_20-30k/hf_ckpt`）起训，`random_aug_stage2.yaml`，优化器和学习率从头开始（5e-5 → 1e-5）。当前默认是 v3，输出 `output_stage2_v3/`：

- v3 = v2 + `mask_padded_actions`（episode 末尾补齐的动作不计损失，本机 A/B clean +2.8、randomized +5.1）。
- v3 训 2500 步、每 500 步存一个、5 个全部保留：v2（5000 步，50×20）的 randomized 3k EMA 44.1 > 4k EMA 39.8 > 5k 38.8，越训越差。
- `output_stage2/`、`output_stage2_v2/` 是前两版，用同一目录会从它断点续训。

第一版（`random_aug_s2.yaml`，已删）randomized 降的根因是 teacher_clean，见 `clean随机化增强指南.md` §3。

```bash
cd /data/zhangmingfa/RoboTwin2
git stash && git pull && git stash pop   # robotwin_local.yaml 里改过模型路径，先 stash
df -h /data                              # 5 个 checkpoint 约 630G，存盘时短暂多一个
# 冒烟（几分钟）
STEPS=20 SAVE=20 OUT=output_stage2_v3_smoke/ bash run_train_stage2_4gpu.sh 2>&1 | tee lingbot-vla-v2/train_stage2_v3_smoke.log
grep mask_padded_actions lingbot-vla-v2/output_stage2_v3_smoke/lingbotvla_cli.yaml   # 应为 true
# 正式（约 9.3 s/步，2500 步约 6.5 小时）
setsid nohup bash run_train_stage2_4gpu.sh > lingbot-vla-v2/train_stage2_v3_$(date +%m%d_%H%M).log 2>&1 < /dev/null &
pkill -f train_lingbotvla.py   # 停止；用相同命令重跑即断点续训
```

- 冒烟通过的标准：
  - 日志有 `random_aug: prob=0.5 arm_masks=True textures=5640 files + procedural, distractors=3060` 和 `EMA decay=0.99 every=10`。
  - 前几步 `VLA_Loss` 约 0.01–0.03；约 0.36 说明没加载上 checkpoint。
  - 20 步跑完，`global_step_20/` 下有 `hf_ckpt` 和 `ema_hf_ckpt`。
  - 跑的时候 `free -g` 看一眼主机内存（EMA 每卡在 CPU 上约多占 6–13G）。
  - 然后删掉 `output_stage2_v3_smoke` 正式开跑。
- EMA 0.99（openpi 的做法）：只额外存一份滑动平均权重 `ema/`、`ema_hf_ckpt/`，原始训练不变；`EMA=0` 关闭。
- soup 不在 A100 上时用 `INIT=<hf_ckpt 路径>` 指定。
- 额外参数原样传给训练，例如 `OUT=output_stage2_x/ bash run_train_stage2_4gpu.sh --train.max_steps 3000`。
- 评测（50×20）：EMA 按 1000 → 2000 → 500 → 1500 → 2500 的顺序评，结果在 `eval_result/stage2_v3/`，评完的可随时中断：

```bash
cd /data/zhangmingfa/RoboTwin2
setsid nohup bash -c 'for s in 1000 2000 500 1500 2500; do OUTPUT_BASE=$PWD/eval_result/stage2_v3 TEST_NUM=20 RAND_CLIENTS_PER_GPU=6 bash run_eval_4gpu.sh lingbot-vla-v2/output_stage2_v3/checkpoints/global_step_$s/ema_hf_ckpt 8; done' > eval_stage2_v3_$(date +%m%d_%H%M).log 2>&1 < /dev/null &
```

```bash
# 快速子集
TASKS="lift_pot handover_mic beat_block_hammer click_bell place_shoe stack_blocks_two open_laptop place_empty_cup shake_bottle turn_switch" TEST_NUM=20 \

pkill -f scripts/eval.sh
```
