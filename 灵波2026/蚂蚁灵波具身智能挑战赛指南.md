# 蚂蚁灵波具身智能挑战赛 · RoboTwin2 实战文档

> 适用仓库：`zmf2022/RoboTwin2`（`main` 分支）
> 模型：官方 LingBot-VLA 2.0（已并入本仓库 `lingbot-vla-v2/`，来自 `https://github.com/Robbyant/lingbot-vla-v2.git` @ ecca77b）
> 仿真：RoboTwin 2.0（默认 embodiment `aloha_agilex`，50 双臂任务）
> 本机实测：`NVIDIA RTX PRO 5000 72GB × N`，Driver `595.84`，`conda 26.3.2`
> 全程走官方流程，不用 XPolicyLab。


```bash
hf download TianxingChen/RoboTwin2.0 \
  lerobot_dataset/RoboTwin_lerobot_v30.zip \
  --repo-type dataset --local-dir data

unzip data/lerobot_dataset/RoboTwin_lerobot_v30.zip -d data/training_data/
```

产物 `data/training_data/RoboTwin_lerobot_v30/`：Aloha-Agilex 50 任务 × 50 条 clean，
共 2500 集，LeRobot v3.0 格式


### 3.2 randomized 数据转 LeRobot（仅供评测/泛化对比，禁止参与训练）

仿真评测（§5.2 `--task_config demo_randomized`）不需要数据；
只有拿 random 轨迹做训练对比时才需要转。转换脚本已移植在 `scripts/convert/`

```bash
# 1. 下载 50 任务 randomized zip，解到 data/<task>/<setting>/
hf download TianxingChen/RoboTwin2.0 \
  --repo-type dataset \
  --include "dataset/*/aloha-agilex_randomized_500.zip" \
  --local-dir raw_randomized
for z in raw_randomized/dataset/*/aloha-agilex_randomized_500.zip; do
  t=$(basename "$(dirname "$z")")
  mkdir -p "data/$t" && unzip -q -o "$z" -d "data/$t"
done

# 2. 逐任务 process（取 50 条；要全 500 把 50 改 500）+ 转 LeRobot v3.0
bash scripts/convert/convert_to_lerobot.sh process_all aloha-agilex_randomized_500 50
bash scripts/convert/convert_to_lerobot.sh generate processed_data demo_randomized
```

产物：`$HF_LEROBOT_HOME/demo_randomized/`（默认 `~/.cache/huggingface/lerobot/`）。

## 4. 模型训练

### 4.1 全参微调（多卡，效果最好）

单卡 72GB 放不下 6.4B 全参训练，需多卡：

| 卡数 | MBS | 备注 |
|---|---|---|
| 2 | 1～2 | 需加 `--train.enable_full_shard true` |
| 4 | 4 | 最低推荐 |
| 8 | 8～16 | 推荐 |

```bash
cd lingbot-vla-v2
conda activate robotwin
NGPU=$(nvidia-smi -L | wc -l)
MBS=8
bash ../scripts/train.sh ../scripts/robotwin_local.yaml \
  --train.micro_batch_size $MBS \
  --train.gradient_accumulation_steps $((1024 / (MBS * NGPU))) \
  --train.global_batch_size 1024 \
  --train.enable_gradient_checkpointing true \
  --data.num_workers 4 \
  --data.prefetch_factor 1
```

- global batch 固定 1024（= MBS × NGPU × 累积），OOM 就把 MBS 减半。
- `num_workers` / `prefetch_factor` 必须调小，默认值（20/4）会撑爆主机内存。
- 日志：`lingbot-vla-v2/log.txt`；checkpoint：`lingbot-vla-v2/output/checkpoints/global_step_<N>/hf_ckpt/`。

### 4.2 非全参微调（单卡）

冻结 Qwen3-VL（4.44B），只训 action expert + 对齐头（1.93B）。

```bash
cd lingbot-vla-v2
conda activate robotwin
MBS=4   # OOM 改 2
bash ../scripts/train.sh ../scripts/robotwin_local.yaml \
  --train.train_expert_only true \
  --train.output_dir output_expert/ \
  --train.max_steps 12000 \
  --train.save_steps 6000 \
  --train.micro_batch_size $MBS \
  --train.gradient_accumulation_steps $((1024 / MBS)) \
  --train.global_batch_size 1024 \
  --train.enable_gradient_checkpointing true \
  --data.num_workers 4 \
  --data.prefetch_factor 1
```

保效果要点：
- 单卡 50k 步需约 68 天，改为 12000 步（约 22 epoch、16 天），余弦 lr 在 12000 步内退火完；batch 1024、lr 1e-4、FP32 不变。
- 两个 checkpoint 都评测，按 clean + randomized 均值选（冻结 VLM 后 randomized 泛化通常更稳，clean 可能偏低）。
- 评测：`bash scripts/eval.sh lingbot-vla-v2/output_expert/checkpoints/global_step_<N>/hf_ckpt 1 10`。

### 4.3 LoRA 微调（单卡，非全参里效果最好）

action expert（1.79B）+ 对齐头全参训练；VLM 的 LLM 部分（q/k/v/o/gate/up/down，36 层）挂 LoRA（r=32、alpha=64，66.1M 参数），视觉塔、embedding、LayerNorm 冻结。与 4.2 相比 VLM 能适配仿真画面，深度/视频蒸馏也能反传到 VLM。

实测（batch 32 每步耗时，单卡）：基线 MBS 4 + 梯度检查点 5.04s；关检查点 4.36s；MBS 8 4.43s；多加 dataloader 进程无效（GPU 利用率已 95%）；**MBS 8 + 关检查点 + expandable_segments 4.03s（快 20%，峰值显存 69.8G）**，以上均不改 batch/超参，效果等价。

```bash
cd lingbot-vla-v2
conda activate robotwin
MBS=8   # OOM 退回 MBS=4
PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True \
bash ../scripts/train.sh ../scripts/robotwin_local.yaml \
  --train.lora_rank 32 \
  --train.lora_alpha 64 \
  --train.output_dir output_lora/ \
  --train.max_steps 50000 \
  --train.save_steps 20000 \
  --train.micro_batch_size $MBS \
  --train.gradient_accumulation_steps $((256 / MBS)) \
  --train.global_batch_size 256 \
  --train.enable_gradient_checkpointing false \
  --data.image_augment true \
  --data.num_workers 4 \
  --data.prefetch_factor 1
```

- `image_augment`：训练时亮度 0.7～1.3、对比度 0.6～1.4、饱和度 0.5～1.5 抖动（同一样本各视角一致），对应 randomized 的光照变化，耗时 +3%。
- LoRA 参数走 AdamW，其余可训参数仍用 Muon；保存 `hf_ckpt` 时自动把 LoRA 合并回原权重（已验证：无 LoRA 键、键名与基座一致、冻结部分不变），评测命令不变：`bash scripts/eval.sh lingbot-vla-v2/output_lora/checkpoints/global_step_<N>/hf_ckpt 1 10`。
- 未调优项：r 32/64、LoRA lr。
- 实现：`lingbotvla/utils/vla_lora.py`，`--train.lora_rank 0`（默认）即关闭。

## 5. 模型评估

直接在本仓库评测（`scripts/eval.sh` + `scripts/eval_lingbotvla_client.py`，协议同 LingBot 官方：种子 100000 起、专家校验、每任务 100 次、unseen 指令、FP32）。
一条命令跑完 50 任务 × clean + randomized × 100 次：

```bash
conda activate robotwin
bash scripts/eval.sh <模型目录> [num_gpus] [clients_per_gpu]   # 每卡 1 个推理 server，多个仿真 client 共用（每 client 约 1 核 CPU、3G 显存）
```

官方在 clean+randomized 上后训练的对照模型（README 报告 clean 93.52% / randomized 92.80%，**用了 randomized 数据，不可比、禁止作为提交起点**），仅用于评测链路对拍与差距分析：

```bash
bash scripts/eval.sh /mnt/datadisk/models/lingbot-vla/lingbot-vla-v2-6b-robotwin/checkpoints/global_step_50000/hf_ckpt 1 10
```

### 5.2 微调后模型

## 7. 常见坑

| 现象 | 解法 |
|---|---|
| 推理找不到 Qwen 权重 | 检查 `QWEN3VL_PATH` 是否指向 `Qwen3-VL-4B-Instruct` 目录 |
| `eval.sh` 报 `no config.json` | 参数必须指到 `checkpoints/global_step_<N>/hf_ckpt/`，不是父目录 |
| 训练进程无报错直接消失（日志停在第一个 batch） | 主机内存 OOM：加 `--data.num_workers 4 --data.prefetch_factor 1` |
| 训练 `CUDA out of memory` | 减小 `MBS` 并相应增大梯度累积；单卡 72GB 无法全参训练，需 ≥2 卡 |
| 评测显存不够 | 每卡 1 个 server 约 26GB + 每个 client 约 3GB，减小 `clients_per_gpu`；训练与评测不能同卡同时跑 |
| 下载慢 / 断 | `HF_ENDPOINT=https://hf-mirror.com` + `hf_transfer` |
| 成绩与官方对不上 | 确认 FP32 + `demo_clean` + `use_length` 默认 50 未改 |
